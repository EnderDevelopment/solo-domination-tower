# Solo Domination Tower Scripts

This project provides enhanced scripts for the Gargoyle Tower and Ice Tower in Roblox's Tower Defense game, specifically designed for solo domination in the 2026 Tower Update. The scripts include increased attack range, speed, and damage, as well as special abilities like freezing enemies. The scripts are written in Lua and are designed to be placed within the Roblox game environment.

## Install

1. Download the scripts from the GitHub repository.
2. Open your Roblox Studio project.
3. Navigate to the Tower Defense game environment.
4. Locate the Gargoyle Tower and Ice Tower within the Workspace/Towers folder.
5. Replace the existing scripts with the downloaded scripts.

## Use

1. Launch the Roblox game in Roblox Studio.
2. Place the Gargoyle Tower or Ice Tower in your game environment.
3. The towers will automatically enhance their stats and abilities as specified in the scripts.
4. Enjoy the enhanced towers in your solo domination strategy.
